# GDG RBU — Frontend Website

A responsive React website inspired by the Figma design for Google Developer Groups at Ramdeobaba University (RBU).

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Light and dark mode toggle
- Animated hero section and smooth transitions
- Upcoming events section with event cards
- Team introduction section
- Interactive FAQ accordion
- Contact information and social links
- Interactive buttons and hover effects

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS3
- Lucide React
- Google Fonts

## 🚀 Run Locally

### Prerequisites

Install Node.js (LTS): https://nodejs.org/

### Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
4. STart the develeopment server:
npm run dev
5.Open the local URL shown in the terminal
